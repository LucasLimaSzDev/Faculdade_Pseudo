## Overview

Repository for college programming logic activities written in pseudocode.

This repository is organized as a clean academic archive and portfolio. Each
activity should be easy to find, read, run and review later.

## Focus

- Programming logic
- Algorithms
- Step-by-step reasoning
- Structured problem solving
- College assignments and study notes

## Structure

~~~text
assignments/
  semester-01/
    list-01/
      README.md
      solution-file
docs/
  INDEX.md
templates/
  activity/
~~~

## How To Add A New Activity

1. Create a folder inside the assignments/semester-01/ directory.
2. Use a short folder name, such as list-02, exam-practice or arrays.
3. Add a README.md explaining the activity.
4. Add the solution source file.
5. Keep filenames lowercase and descriptive.

## Running

Pseudocode files are meant to be read as algorithm descriptions. When an
exercise is implemented in a specific tool used by the course, add the tool name
and execution steps inside that activity folder.
